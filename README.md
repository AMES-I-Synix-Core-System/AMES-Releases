# AMES I - Synix Core System — Releases

Finished AMES installers and in-app updates only. The AMES source code is private.

- **Install:** download `AMES_x.y.z_x64-setup.exe` from the newest release and run it.
- **Updates:** once installed, AMES finds new versions by itself (AMES Systems › Status › AMES Updates). Every update is signed with the AMES update key; AMES refuses anything unsigned.
- A registration key is needed to use AMES.
